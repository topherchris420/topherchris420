# Earlier experiments

The archive, read as strata.

Twenty-nine original repositories are archived. They stay public because they are part of the record: some are precursors, some became components, some are dead ends, and some were simply worth trying. Read in order, they also show a lab learning what its tools are good for.

**Ground rules for this page.** Each description comes from the repository's own README. A reason for archiving is given only where the repository records one; none of them do, so none is given. "What happened" names a later project only where the connection is explicit — the same name, the same stated idea, or reused code. Looser echoes are called echoes. Forks of other people's projects are left out.

---

## Stratum II · mid-2025 — the generative burst

Twenty-four of the archived repositories were started between May and August 2025, and one more in October. In most of them, the majority of commits were authored by an AI app builder. Many were built in a day or two. The ideas were large, and the READMEs often described them as finished systems.

---

What the strata show, read bottom to top: the ambition barely changed. The same few questions — signals, bodies, location, agency — run through all three layers. What changed is what the work is willing to claim, and how it lets itself be checked.
