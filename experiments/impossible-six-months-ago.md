# Impossible six months ago

A running list of things that recently crossed, for one person working in this lab, from *not worth attempting* to *attemptable*.

"Impossible" is shorthand. None of these were impossible in principle, and many were done earlier by teams with more time and money. The list records something narrower: the moment an assumption about what one person could reasonably try stopped being true here. It is revisited every six months, because the line keeps moving and the old assumptions go stale quietly.

Each entry names the repository where it was attempted, the date it first appears in Git, and — the part that matters — what it still cannot tell us.

## Still out of reach

The list is only honest with its complement. These remain slow or out of reach no matter how fast the code arrives:

- Fabricating and safety-reviewing hardware that connects to a person.
- Interferometry at the precision the location-as-resonance predictions require.
- Flight testing.
- Independent reproduction by someone who is not the author.
- Knowing, rather than hoping, that a model's judgment is good — which takes many measured outcomes, not one fluent answer.

## Revisiting

Every six months: re-read the "still out of reach" list first. Move an item up only with a repository that attempted it. When an entry here turns out to have been wrong about what became possible, keep it and add a note.
