# A superseded plan

The two documents in this folder planned a June 2026 version of the profile built from badges, statistics cards, and a contribution-snake animation. That direction was dropped in September 2026. The current editorial rules in [`docs/profile-maintenance.md`](../profile-maintenance.md) forbid every one of those elements, and the workflow the plan relied on no longer exists.

They stay here for the same reason archived repositories stay public: a discarded approach is part of the record. Nothing in them describes the current profile.
