# Pine Gap Boogie

Christopher’s [CHRISW character](https://github.com/topherchris420/satellite-vision-scape/blob/49626bf71f56cf6db84c669e6a04accdb5a77865/gta-sa-99-9-percent-sure/docs/CHARACTER.md) dances for eight beats at 120 BPM. On the fifth tap he plants his sneaker, holds still as the label scratches backward, then glances down. The [animated GLB](pine-gap-boogie.glb) contains the rig, textures, platter, five groove inlays, and dance clip.

Side B samples *Green Machine*, written and recorded by Christopher Woodyard as Indigo People. Each step plays a short, pitch-isolated cut from a different track. All five cuts return together under the backspin, voicing Gm11 (G, B♭, D, F, C).
